# rondo

One badge per Rondo result, drawn by Claude as vector stickers (SVG masters here; 512 px PNGs in
`Assets/_Project/Resources/Rondo`). Style from the disaster-badge references: round sticker, thick
dark outline, dotted inner ring, one bold icon. The Rondo banner shows the badge with its own motion
(RondoBadge.cs); Reduce motion keeps it still.

| Result | File | Icon | Motion |
|---|---|---|---|
| Purge | rondo_purge | three cards on fire | flame flicker (scale pulse) |
| Trading Only | rondo_trading_only | two cards swapping | rocks back and forth |
| Hunger Disaster | rondo_hunger | empty SARDINAS can, flies | nervous shake |
| Tornado | rondo_tornado | funnel with debris | spins |
| Doomsday Clock | rondo_doomsday | cracked clock near midnight | ticks, one step a second |
| Blackout | rondo_blackout | dead bulb, struck through | slow dim flicker (under 3 per second) |
| Outbreak | rondo_outbreak | sick toxic cloud | queasy wobble |
| Peaceful Day | rondo_peaceful | smiling sun | floats and turns gently |

The design team can repaint any badge: keep the file name and a 512 x 512 transparent PNG.
