# room props (v1, Nov 26)

Bunker-room details drawn by Claude as vector props (SVG here; PNG at 2x in
`Assets/_Project/Resources/Room`). Placed by `RoomDetails.cs` only where the wall is free: above the
heads and between the seats, clear of the HUD on the left and top right.

| Prop | File | In the game |
|---|---|---|
| Supply shelf (3 stages) | room_shelf_1/2/3 | full on Days 1-3, half on 4-7, almost empty on 8-10 (checklist A18) |
| Wall calendar | room_calendar | "Botika Silong" drugstore calendar; big number = days left before dark |
| BAWAL sign | room_bawal_sign | "BAWAL ANG PANG-TATLO!" hand-painted board |
| Silong poster | room_poster_silong | rubber-hose sun mascot waving, "SAFE NA SAFE!" (checklist A20 draft) |
| Electric fan | room_fan | broken, with a "SIRA. HUWAG GALAWIN" tag |
| Wall crack | room_crack | grows from small to full size over the 10 Days |
| Fly | room_fly | three circle the lamp; hidden at Night and with Reduce motion |

All brands are made up. The design team can repaint any prop: keep the file name and roughly the
same proportions.
